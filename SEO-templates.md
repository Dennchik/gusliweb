# SEO-шаблоны title / description — Gusli Web

Готовые тексты для вставки в поля ACF **«SEO»** (группа «SEO», поля
`seo_title` и `seo_description`). Если поле оставить пустым, тема
сформирует значение автоматически по [inc/seo.php](inc/seo.php).

> **Правила:**
> - `title` — до **60 символов** (в админке стоит лимит 70 с запасом).
> - `description` — до **160 символов**.
> - Бренд в конце: **Gusli Web** (или GUSLI MEDIA — выберите один и везде используйте одинаково).
> - `{…}` — подставить своё значение.

## Что уже делает тема автоматически (inc/seo.php)

| Элемент | Поведение |
| --- | --- |
| `<title>` | «Название — Gusli Web»; переопределяется полем `seo_title` |
| meta description | `seo_description` → отрывок → начало контента (до 160 симв.) |
| canonical | permalink страницы/записи/термина |
| robots | `noindex` для поиска, 404 и пагинации со 2-й страницы |
| Open Graph / Twitter | title, description, image, url, type |
| Schema.org | Organization, WebSite, BreadcrumbList, FAQPage (главная), Article (записи) |

## Что нужно сделать вручную

1. В настройках WordPress проверьте **Название сайта** и **Краткое описание**
   (они попадают в `<title>`, meta и Schema).
2. Вставьте готовые тексты выше в поля группы **«SEO»** на нужных страницах.
3. При необходимости скорректируйте данные организации (email, телефон,
   соцсети) в `gusli_seo_organization()` в [inc/seo.php](inc/seo.php).
4. Проверьте `sitemap.xml` и `robots.txt` (через Настройки → Постоянные ссылки /
   любой SEO-плагин, если решите его добавить).
